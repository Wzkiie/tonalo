# Security

## Reporting a problem

If you find a security problem in Tonalo – for example a way to get at someone's login token or custom headers – please report it privately instead of opening a public issue:

**[Report a vulnerability](https://github.com/Wzkiie/tonalo/security/advisories/new)** (GitHub's private reporting, only visible to the maintainer)

Please describe what you found and how to reproduce it. Don't include real tokens, passwords or server addresses – a made-up example is enough. You'll get an answer as soon as possible; this is a hobby project, so it may take a few days.

## Supported versions

Fixes go into the latest release of the TV app and the current code of the iPhone app. Older versions don't get updates.

## How Tonalo handles your login

See the [Security section in the README](README.md#security) and the [privacy policy](PRIVACY.md). In short: the password is never stored, the apps only talk to the server you enter, and nothing is sent anywhere else.
